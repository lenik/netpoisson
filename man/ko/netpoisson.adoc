== 이름

netpoisson - 푸아송 과정으로 요청을 보내거나 응답한다

== 개요

*netpoisson* [_옵션_]... [_서버_]

== 설명

*netpoisson* 는 요청을 수신하거나 _서버_ 에 연결해 푸아송 과정으로 요청을 보냅니다.
도착 간격은 평균 1/λ 의 지수분포입니다. 기본값은 초당 100요청입니다.

각 요청은 *ECHO* 또는 *STATUS* 입니다. *ECHO* 응답은 요청 바이트 그대로입니다.
*STATUS* 는 서버 시간선과 수신/송신 대기열 깊이를 담습니다. 부하는 *ECHO* 를 쓰고
다른 소켓으로 *STATUS* 를 조회합니다.

_서버_ 를 생략하거나 *-d* 를 주면 수신합니다. _서버_ 는 호스트 또는 `호스트:포트` 입니다.

시간은 100ms 조각으로 표시됩니다. 최신 조각이 왼쪽이고 줄은 오른쪽으로 흐릅니다.
가운데 숫자는 아직 이 호스트를 떠나지 않은 송신 대기입니다. 응답 줄에서 화살표 왼쪽은
아직 읽지 않은 요청, 다음은 아직 보내지 않은 응답입니다.

*-w* 는 같은 시간선과 RTT, RFC 3550 지터, 손실, 대기열 지연을 HTTP로 보여 줍니다.
*-s* 는 지정 초 후 JSON 보고서를 표준 출력에 씁니다.

== 옵션

*-d, --daemon*::
  수신한다(_서버_ 생략 시 기본). _서버_ 와 함께 쓰지 마십시오.

*-H, --host _HOST_*::
  바인드 주소(기본 `0.0.0.0`). 클라이언트 대상은 _서버_ 입니다.

*-p, --port _PORT_*::
  바인드 또는 접속 포트(기본 1871). 0은 임시 포트입니다.

*-u, --udp*::
  UDP 사용(기본 TCP).

*-l, --lambda _N_*::
  초당 *ECHO* 수(기본 100). 클라이언트만.

*-s, --stats _SECS_*::
  _SECS_ 초 후 JSON 보고.

*-w, --web*::
  대시보드를 열고 브라우저를 띄운다. `NETPOISSON_NO_BROWSER=1` 로 생략.

*--web-host _H_*::
  대시보드 주소(기본 `127.0.0.1`).

*--web-port _N_*::
  대시보드 포트(기본 8711).

*-v, --verbose*::
  더 자세한 로그.

*-q, --quiet*::
  상태 줄을 그리지 않음.

*-h, --help*::
  사용법을 출력하고 종료.

*--version*::
  버전과 라이선스를 출력하고 종료.

== 종료 상태

*0*::
  성공.

*1*::
  오류, 또는 보냈는데 응답이 없음.
