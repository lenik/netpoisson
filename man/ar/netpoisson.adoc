== الاسم

netpoisson - تقديم طلبات بعملية بواسون، أو الرد عليها

== الملخص

*netpoisson* [_خيار_]... [_خادم_]

== الوصف

*netpoisson* يستمع للطلبات، أو يتصل بـ _خادم_ ويرسل الطلبات كعملية بواسون.
الفواصل بين الوصولات أسية بمتوسط 1/λ. المعدل الافتراضي 100 طلبًا في الثانية.

كل طلب هو *ECHO* أو *STATUS*. استجابة *ECHO* هي بايتات الطلب نفسها.
*STATUS* يعيد الخط الزمني للخادم وعمق طابوري الاستقبال والإرسال. الحمل يستخدم
*ECHO*، ومقبس ثانٍ يستعلم بـ *STATUS*.

بدون _خادم_ (أو مع *-d*) يستمع. _خادم_ هو مضيف أو `مضيف:منفذ`.

يُعرض الوقت بشرائح 100 مللي ثانية. الأحدث على اليسار؛ والسطران يتحركان يمينًا.
الرقم في الوسط هو طابور الإرسال المحلي. يسار السهم في Resp: طلبات لم تُقرأ بعد؛
ثم: ردود لم تُرسل بعد.

*-w* يقدّم نفس الخطوط عبر HTTP مع RTT واهتزاز RFC 3550 والفقدان وتأخير الطابور.
*-s* يطبع تقرير JSON بعد _SECS_ ثانية.

== الخيارات

*-d, --daemon*::
  الاستماع (وهو الافتراضي أيضًا بدون _خادم_). لا تجمعه مع _خادم_.

*-H, --host _HOST_*::
  عنوان الربط (الافتراضي `0.0.0.0`). في وضع العميل الهدف هو _خادم_.

*-p, --port _PORT_*::
  منفذ الربط أو الاتصال (الافتراضي 1871). 0 يطلب منفذًا مؤقتًا.

*-u, --udp*::
  استخدام UDP (الافتراضي TCP).

*-l, --lambda _N_*::
  طلبات *ECHO* المعروضة في الثانية (الافتراضي 100). للعميل فقط.

*-s, --stats _SECS_*::
  طباعة تقرير JSON بعد _SECS_ ثانية.

*-w, --web[=_ADDR_]*::
  تشغيل لوحة مباشرة. الربط الافتراضي `127.0.0.1:3871`.
  سمات WorldMan (الافتراضي `dark-x-files`؛ الفاتح قبل الداكن داخل كل مجموعة).
  إيقاف مؤقت، Runnings/Raw events، ضبط λ/bucket/status عبر `POST /api/config`، و**dense**
  (Runnings 0.25×/0.5×/1×/2×؛ Raw 0.5×/1×/2×) حيث النافذة = `default × dense`.
  View يغيّر الاتجاه فقط؛ Front/Top/Free تشترك في التدوير/التكبير/الإزاحة.
  Spectrum مخطط طيفي بنافذة منزلقة (X يبقى الزمن) مع سمة ألوان.
  `NETPOISSON_NO_BROWSER=1` أو *--no-open* لتخطي فتح المتصفح.

  منفذ اللوحة (الافتراضي 8711).

*-v, --verbose*::
  مزيد من السجلات.

*-q, --quiet*::
  عدم رسم سطري الحالة.

*-h, --help*::
  عرض المساعدة والخروج.

*--version*::
  عرض الإصدار والرخصة والخروج.
