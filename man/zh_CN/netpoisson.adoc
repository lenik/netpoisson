== 名称

netpoisson - 按泊松过程发送请求，或应答这些请求

== 大纲

*netpoisson* [_选项_]... [_服务器_]

== 描述

*netpoisson* 要么监听请求，要么连接到 _服务器_，并按泊松过程发出请求。
到达间隔服从均值为 1/λ 的指数分布。默认速率为每秒 100 个请求。

每个请求是 *ECHO* 或 *STATUS*。*ECHO* 的响应与请求字节相同。
*STATUS* 的响应带回服务器时间线，以及接收队列和发送队列的深度。
负载使用 *ECHO*。第二条套接字用 *STATUS* 探询，这样在数据口堵塞时仍能看到这些数字。

若省略 _服务器_，*netpoisson* 进入监听。*-d* 选择相同模式。
_服务器_ 是主机或 `主机:端口`。*-p* 覆盖端口。

时间按 100 毫秒一片显示。在终端上客户端会重绘两行。
最新的时间片在左边，因此行向右滚动：

 Req. [每个时间片的到达 -> 本机发送队列 -> 更早的到达]
 Resp [            未读取 -> 服务器发送队列 -> 更早的响应]

请求行中间的数字是还没有离开本机的请求。响应行上，箭头左边是服务器尚未读取或分析的请求，
下一个数字是尚未离开服务器的响应。

*-w* 通过 HTTP 提供相同的时间线，以及往返时延、RFC 3550 抖动、丢失、排队时延，
并检查到达间隔是否仍像指数分布。页面是写死的模板，网络允许时会加载 Tailwind CSS。

*-s* 运行给定秒数后，在标准输出打印一个 JSON 对象。实时两行写到标准错误。*-q* 关掉它们。
若已发出请求却一个响应都没回来，客户端以状态 1 退出。

== 选项

*-d, --daemon*::
  监听请求。省略 _服务器_ 时这也是默认行为。不要同时传入 _服务器_。

*-H, --host _HOST_*::
  绑定地址。默认是 `0.0.0.0`。客户端模式下目标是 _服务器_，不是该地址。

*-p, --port _PORT_*::
  绑定或连接的端口。默认是 1871。端口 0 让内核分配临时监听端口。

*-u, --udp*::
  使用 UDP。默认是 TCP。TCP 套接字会设置 `TCP_NODELAY`。

*-l, --lambda _N_*::
  每秒发出的 *ECHO* 请求数。默认是 100。_N_ 必须为正，可为小数。仅对客户端有效。

*-s, --stats _SECS_*::
  运行 _SECS_ 秒后打印 JSON 报告。客户端会短暂等待已在途的响应，其余计为丢失。

*-w, --web*::
  提供实时仪表盘并在浏览器中打开。设置 `NETPOISSON_NO_BROWSER=1` 可跳过打开浏览器。

*--web-host _H_*::
  仪表盘绑定地址。默认是 `127.0.0.1`。

*--web-port _N_*::
  仪表盘端口。默认是 8711。

*-v, --verbose*::
  重复使用以输出更多日志。一次 *-v* 会报告连接情况。

*-q, --quiet*::
  不绘制实时状态行。若同时给定 *-v* 与 *-q*，后出现的一方决定显示；*-q* 关闭日志。

*-h, --help*::
  打印用法摘要并成功退出。

*--version*::
  打印版本与许可证信息并成功退出。

== 退出状态

*0*::
  成功。

*1*::
  发生错误，或客户端发出了请求却未收到任何响应。
