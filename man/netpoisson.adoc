== Name

netpoisson - offer a Poisson stream of requests, or answer them

== Synopsis

*netpoisson* [_OPTION_]... [_SERVER_]

== Description

*netpoisson* either listens for requests, or connects to _SERVER_ and offers
requests as a Poisson process on an absolute monotonic schedule. The
inter-arrival time is exponential with mean 1/λ. The default rate is 100
requests per second.

TCP and UDP use a length-prefixed binary PDU (protocol version 2). An *ECHO*
response without a telemetry trailer is byte-identical to the request. With
telemetry, the same payload is returned and a fixed trailer carries queue and
byte counters so frequent *STATUS* probes are optional. *STATUS* returns a
fixed window of server timelines (default 120 × 100 ms) plus queue depths.

SSH stdio mode (*--ssh* / *--stdio-server*) uses `@nPoi` NDJSON lines instead
of the binary PDU. Only lines with that prefix are protocol; other stdout is
treated as remote noise. Responses are flushed immediately.

The client validates sequence correspondence, payload identity, duplicates,
reordering, loss, RTT, and schedule skew (actual send time versus the planned
Poisson instant).

If _SERVER_ is omitted, *netpoisson* listens. *-d* selects the same mode.
_SERVER_ is a host or `host:port`. *-p* overrides the port.

On a TTY the client redraws compact Req/Resp lines (newest bucket on the
left). The web UI shows four timelines: Req, Recv, Resp, Ack. When standard
output is not a TTY, live UI is suppressed and NDJSON or a final JSON report
is written instead.

*-w* serves a live dashboard with timelines, RTT, jitter, loss, analysis
notes, netpoisson-induced bandwidth, and session rx/tx bytes.

*-s* runs for the given duration and then prints one JSON report on standard
output. If requests were sent and none came back, the client exits with
status 1.

== Options

*-d, --daemon*::
  Listen for requests. This is also the default when _SERVER_ is omitted.

*--stdio-server*::
  Serve the `@nPoi` NDJSON protocol on standard input/output (for SSH).

*--ssh _TARGET_*::
  Run as a client over SSH stdio to _TARGET_. Starts `ssh -T` with safe
  default `-o` options and the remote *--stdio-server* command.

*--ssh-command*, *--remote-command*, *--ssh-option*::
  Override the ssh binary, remote command, or add `-o KEY=VALUE` (repeatable).

*--install*, *--remove*::
  Write or remove a systemd `--user` unit for the daemon.

*-H, --host _HOST_*::
  Address to bind. Default `0.0.0.0`.

*-p, --port _PORT_*::
  Port to bind or connect to. Default 1871.

*-u, --udp*::
  Use UDP. Default is TCP. Cannot combine with *--ssh*.

*--tls*::
  Enable TLS on TCP (self-signed cert if *--cert*/*--key* omitted). On UDP, enable PSK datagram sealing (requires *--psk*).

*--psk _TEXT_*::
  Pre-shared key for UDP sealing.

*--cert*, *--key*, *--tls-ca*, *--tls-insecure*::
  TLS certificate material and client verify controls.

*-l, --lambda _RATE_*::
  Mean *ECHO* requests per second. Default 100.

*--payload _SIZE_*::
  Payload size (for example `64`, `1k`). Default 64B.

*--connections _N_*::
  Parallel TCP connections. Default 1.

*--max-pending _N_*::
  Cap on the client pending queue.

*--status-interval _D_*::
  *STATUS* probe interval. Default `100ms`.

*--bucket _D_*, *--window _D_*::
  Timeline bucket and visible window. Defaults `100ms` and `12s`.

*--seed _N_*::
  Reproducible RNG seed for inter-arrivals and payloads.

*--profile _NAME_*::
  `ssh-interactive` or `ssh-bulk` preset.

*-s, --stats _D_*::
  Run for duration _D_ and print a JSON report.

*-w, --web[=_ADDR_]*::
  Serve a live dashboard. Default bind `127.0.0.1:3871`.
  Set `NETPOISSON_NO_BROWSER=1` or pass *--no-open* to skip opening a browser.

*--json*::
  Emit NDJSON events on standard output.

*--report _FILE_*::
  Save the final JSON report.

*-v, --verbose*::
  More logging on standard error.

*-q, --quiet*::
  Suppress the live status lines.

*-h, --help*::
  Print help and exit.

*-V, --version*::
  Print version and exit.

== Examples

  netpoisson -d
  netpoisson -l 100 --payload 64 127.0.0.1
  netpoisson -u -l 50 -s 10 127.0.0.1
  netpoisson -w -l 100 127.0.0.1
  netpoisson --ssh user@host --profile ssh-interactive -s 120
