== 名称

netpoisson - ポアソン過程でリクエストを送る／応答する

== 概要

*netpoisson* [_オプション_]... [_サーバー_]

== 説明

*netpoisson* はリクエストを待ち受けるか、_サーバー_ に接続してポアソン過程でリクエストを送ります。
到着間隔は平均 1/λ の指数分布です。既定は毎秒 100 リクエストです。

各リクエストは *ECHO* または *STATUS* です。*ECHO* の応答はリクエストそのものです。
*STATUS* はサーバの時間線と受信／送信待ち行列の深さを返します。負荷は *ECHO* を使い、
別ソケットで *STATUS* を探ります。

_サーバー_ を省略するか *-d* を付けると待ち受けます。_サーバー_ はホストまたは `ホスト:ポート` です。

時間は 100 ms のスライスで表示されます。新しいスライスが左にあり、行は右へ流れます。
中央の数はまだ自ホストを出ていない送信待ちです。応答行の矢印左は未読リクエスト、次は未送信応答です。

*-w* は同じ時間線と RTT・RFC 3550 ジッタ・損失・待ち行列遅延を HTTP で見せます。
*-s* は指定秒数後に JSON 報告を標準出力へ出します。

== オプション

*-d, --daemon*::
  待ち受ける（_サーバー_ 省略時の既定）。_サーバー_ と同時指定しないでください。

*-H, --host _HOST_*::
  バインド先（既定 `0.0.0.0`）。クライアント時の相手は _サーバー_ です。

*-p, --port _PORT_*::
  バインドまたは接続ポート（既定 1871）。0 は一時ポートです。

*-u, --udp*::
  UDP を使う（既定は TCP）。

*-l, --lambda _N_*::
  毎秒の *ECHO* 数（既定 100）。クライアントのみ。

*-s, --stats _SECS_*::
  _SECS_ 秒後に JSON 報告を出す。

*-w, --web*::
  ダッシュボードを開きブラウザを起動する。`NETPOISSON_NO_BROWSER=1` で抑止。

*--web-host _H_*::
  ダッシュボードのアドレス（既定 `127.0.0.1`）。

*--web-port _N_*::
  ダッシュボードのポート（既定 8711）。

*-v, --verbose*::
  詳しくログする。

*-q, --quiet*::
  状態行を出さない。

*-h, --help*::
  使い方を出して終了する。

*--version*::
  版とライセンスを出して終了する。

== 終了ステータス

*0*::
  成功。

*1*::
  エラー、または送信したが応答が無い。
